I work on LLM inference and other high-performance code (HPC). In my spare time I build C++ developer tools at [clice-io](https://github.com/clice-io):

- [clice](https://github.com/clice-io/clice): a C++ language server for modern C++, focused on high performance and deep code intelligence.
- [xclang](https://github.com/clice-io/xclang): cross-compiling with clang. One PGO+ThinLTO toolchain, six targets' sysroots and static runtimes in every archive, programs that depend only on the OS. Ships as a CMake package, a Bazel module and a conda package.
- [kotatsu](https://github.com/clice-io/kotatsu): a C++23 async runtime with reflection-driven serialization, JSON-RPC and LSP, and cross-platform file system and process APIs.
- [catter](https://github.com/clice-io/catter): a tool to capture C++ compilation commands.

I write about C++, compilers and developer tools at [ykiko.me](https://ykiko.me).
